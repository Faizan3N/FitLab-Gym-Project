# FitLab Athletic Club

FitLab is a full-stack website for a private athletic club. It includes a public marketing site and club tools for members, coaches, attendance, workout plans, and subscriptions.

This project is a single-gym website with membership management. It is not a multi-tenant SaaS.

## Features

### Public website
- Hero, club story, and facilities
- Weekly class timetable
- Coaching faculty
- Membership rates
- Photo gallery, testimonials, and FAQ
- Visit / enquiry form

### Club operations
- Member login and registration
- Attendance check-in and check-out
- Coach registration
- Workout plan creation
- Membership subscription

## Tech stack

- Frontend: React, Vite, React Router
- Backend: Node.js, Express
- Database: MongoDB
- Auth: JWT, bcrypt
